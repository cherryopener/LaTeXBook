GitHub 원고 저장소 연결

원고는 비공개 저장소 cherryopener/textbooks에 저장됩니다. 연결하려면 그 저장소 하나만 읽고 쓸 수 있는 토큰이 필요합니다.

토큰 만드는 법
  1. GitHub 토큰 만들기 화면을 엽니다(GitHub에 로그인).
  2. Token name: 교재 편집기, Expiration: 원하는 기간(예: 1년).
  3. Repository access: Only select repositories → cherryopener/textbooks 하나만 고릅니다.
  4. Permissions → Repository permissions → Contents를 Read and write로 바꿉니다. 다른 권한은 건드리지 않습니다.
  5. 맨 아래 Generate token → 나온 값(github_pat_…)을 복사해 아래 칸에 붙여 넣습니다.

토큰은 이 브라우저에만 저장되고 GitHub 말고는 어디에도 보내지 않습니다. 대화창이나 메일에 붙여 넣지 마세요. 잃어버리면 같은 화면에서 지우고 새로 만들면 됩니다.
