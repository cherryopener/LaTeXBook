# 견본 원고

`sample-book/`은 [원고 형식 명세](../docs/FORMAT.md)의 문법을 모두 한 번 이상 쓰는 견본 책입니다. 각 모듈은 이 견본이 아래 기대 결과대로 처리되는지로 합격을 판단합니다. 내용은 새로 쓴 시험용 글이며, Physiklar 원고(비공개)는 이 공개 저장소에 넣지 않습니다.

## 구성

| 부 | 색 묶음 | 장 |
|---|---|---|
| 1. 운동과 힘 (`1-mechanics`) | `red` (part.json에서 지정) | 1. 속도와 가속도, 2. 힘과 운동 |
| 2. 전기 (`2-electricity`) | `teal` (책 기본값) | 1. 정전기 |
