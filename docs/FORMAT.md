# 원고 형식 명세

편집기가 읽는 원고의 형식입니다. 편집기 화면, 원고 변환, 인쇄 조판, 저장 기능이 모두 이 문서를 기준으로 동작합니다. 바꿀 때는 이 문서를 먼저 고칩니다.

- 확정: 2026-11-07 (1단계)
- 기준: Physiklar의 원고 문법(`docs/WRITING_GUIDE.md`, `lib/markdown.tsx`). 같은 원고가 Physiklar와 이 편집기에서 같은 뜻으로 읽혀야 합니다.
- 견본: `samples/sample-book/` — 이 문서의 문법을 모두 한 번 이상 씁니다. 기능을 만들면 견본이 오류 없이 처리되는지로 확인합니다.

---

## 1. 책 폴더

Physiklar와 같은 구조입니다. 원고는 비공개 저장소 `cherryopener/textbooks`의 `books/` 아래에 둡니다.

```
books/<책 id>/
  book.json                     책 설정
  <n>-<부 이름>/part.json        부 설정
  <n>-<부 이름>/<nn>-<장>.md     장 원고
  images/                       그림
fonts/                          책에 쓰는 글꼴 파일(라이선스상 공개 저장소에 둘 수 없는 것)
```

- 부 폴더와 장 파일의 순서는 이름 앞 숫자로 정합니다(`1-`, `01-`).
- 그림 경로는 원고에서 `images/파일명` 처럼 책 폴더 기준으로 씁니다. Physiklar 경로(`/books/<책 id>/파일명`)도 읽을 수 있어야 합니다(→ `images/파일명`으로 바꿔 읽음).

### 1-1. `book.json`

Physiklar가 쓰는 칸(`title`, `subtitle`, `colors`, `icon` 등)은 그대로 두고, 편집기 설정은 **`print` 안에만** 넣습니다. Physiklar는 `print`를 무시합니다.

```json
{
  "title": "브릿지 물리",
  "subtitle": "역학과 전자기",
  "print": {
    "theme": "cyber",
    "palette": "teal",
    "paper": "a4",
    "series": { "label": ["PHYSICS", "LECTURE NOTES"], "tag": "JUHYUNG" },
    "logo": "images/logo.png",
    "fonts": { "body": "KoPubWorld Batang", "bodyFile": "../../fonts/KoPubWorld_Batang_Light.ttf", "bodyBoldFile": "../../fonts/KoPubWorld_Batang_Bold.ttf" },
    "omitSections": ["실험으로 확인하기", "직접 해 보기"],
    "headingNumbers": true,
    "problemNumber": "000",
    "chapterStart": "left",
    "sideColumn": "outside"
  }
}
```

| 칸 | 값 | 기본값 | 뜻 |
|---|---|---|---|
| `theme` | `"cyber"` | `"cyber"` | 디자인 테마 이름(`themes/<이름>/`) |
| `palette` | `"teal"` \| `"red"` \| `"violet"` | `"teal"` | 색 묶음. 부마다 바꿀 수 있음(1-2절) |
| `paper` | `"a4"` \| `"a4-bleed"` | `"a4"` | 판형. 인쇄할 때 바꿀 수 있음(5절) |
| `series` | 객체 | 없음 | 왼쪽 쪽 머리말의 시리즈 글씨와 이름 태그 |
| `logo` | 그림 경로 | 없음 | 오른쪽 쪽 머리말 로고 |
| `front` | `{ "image": "images/front.png", "title": "Physics Bridge" }` | 없음 | 책 첫 쪽 윗부분 그림과 그 위의 영어 제목(사이버펑크 글꼴). 그림이 없으면 색 띠 |
| `fonts.latin` | `"Tinos"` \| `"EB Garamond"` \| `"none"` | `"Tinos"` | 본문·옆 단 속 로마자와 숫자를 이 글꼴로(숫자는 높이가 가지런한 lining 숫자). Tinos는 Times New Roman과 같은 꼴(Apache-2.0), EB Garamond는 소설책에 흔한 가라몬드(OFL). 한글은 본문 글꼴 |
| `fonts.body` | 글꼴 이름 | Noto Serif KR | 본문 글꼴. `bodyFile`(보통 굵기)과 `bodyBoldFile`(굵은 글씨)이 있으면 그 파일을 불러옴. 경로는 책 폴더 기준(저장소의 `fonts/`는 `../../fonts/…`) |
| `omitSections` | 제목 목록 | `[]` | 인쇄에서 **제목째 통으로** 뺄 절의 제목(3-3절) |
| `headingNumbers` | 참/거짓 | `true` | 절 제목 앞 번호 자동(`1.`, `(1)`) |
| `problemNumber` | `"000"` \| `"0"` | `"000"` | 문항 번호 모양(`001` 또는 `1`) |
| `problemNumbering` | `"book"` \| `"chapter"` | `"book"` | 문항 번호를 책 전체로 이어 매김 / 장마다 `001`부터 |
| `chapterStart` | `"left"` \| `"right"` \| `"any"` | `"left"` | `left`: 부 표지·개념 시작·문제 시작을 모두 **짝수(왼쪽) 쪽**에서(사용자 교재 방식, 필요하면 빈 쪽 자동 삽입). `right`: 부 표지·장은 홀수 쪽, 문제는 새 쪽. `any`: 모두 새 쪽 |
| `sideColumn` | `"outside"` \| `"left"` | `"outside"` | 개념 구간 좁은 단의 자리. `outside`: 펼친 책의 바깥쪽(왼쪽 쪽은 왼쪽, 오른쪽 쪽은 오른쪽). `left`: 항상 왼쪽 |
| `fontSizes` | `{ body?, side?, problem? }` (pt, 0.1 단위) | 없음(본문 10.4, 옆 단 7.6, 문제 8. 문제 기본값은 2026-11-13에 9.6 → 8) | 글자 크기. `body`: 개념 본문(정의 `:::def`·예제 상자 안 글 포함. 팁·참고·생각·주의 상자 안 글은 본문 크기와 상관없이 9pt 고정, 2026-11-13), `side`: 옆 단(좁은 단 용어 풀이), `problem`: 문제 본문(교사용 정답은 문제 크기의 9.2/9.6, 맨 뒤 정답과 해설은 8.4/9.6 비율로 따라감). 범위 본문 8~14, 옆 단 6~11, 문제 7~13. 편집기 위쪽 "글자(pt)" 칸에서 바꾸고 저장하면 여기에 기록됨. 제목·표·교사 메모는 바뀌지 않음 |
| `tocDepth` | `1` \| `2` | `1` | 책 첫 쪽 목차 깊이. `1`: Part·부·장, `2`: 장 아래 절(`##`)까지(번호·쪽수 포함). 장이 적은 책에서 목차 아래가 비지 않게 |

- **저작권 문구는 어디에도 자동으로 넣지 않습니다.** 판권면·꼬리말 저작권 표시 기능은 만들지 않습니다(사용자 결정, 2026-11-07).

### 1-2. `part.json`

```json
{ "title": "운동과 평형", "desc": "…", "print": { "palette": "red" } }
```

- `title`은 부 표지와 부 목차에 나옵니다.
- `print.palette`가 있으면 이 부 안의 장은 그 색 묶음을 씁니다. 없으면 책 기본값.

#### 큰 표지(Part) — 부 위의 단계 (2026-11-07 사용자 결정)

```json
{ "title": "운동의 기술", "print": { "palette": "red", "cover": { "title": "Mechanics" } } }
```

- 책 위계는 **큰 표지(Part) → 부 → 장**입니다. Griffiths 『Introduction to Quantum Mechanics』의 Part I·II 구성을 본뜬 것입니다.
- `print.cover`가 있는 부 **앞에만** 큰 표지가 들어갑니다. 그 부부터 다음 `print.cover` 직전 부까지가 한 Part입니다.
  - 큰 표지: 색 바탕(그 부의 색 묶음) + `PART` + 로마 숫자(I, II, … 자동) + 영어 제목(`cover.title`). 짝수(왼쪽) 쪽.
  - `cover.label`로 `PART` 글자를 바꿀 수 있습니다(기본 `PART`).
- 이 모드에서는 **모든 부**에 흰 바탕 부 쪽(색 테두리 + 큰 부 제목 + 그 부의 장 목록)이 들어갑니다. **언제나 홀수(오른쪽) 쪽**이고, 그 왼쪽은 큰 표지이거나 앞 부의 마지막 쪽입니다(앞 부가 홀수 쪽에서 끝나면 빈 쪽이 하나 들어감).
- 책 첫 쪽 목차는 PART 줄 · 부 · 장 3단계이고, Part마다 한 단(Part 2개면 2단, 3개면 3단, 4개면 4단)으로 나뉩니다.
  - Part가 **5개 이상**이면 Part마다 한 단을 줄 수 없으므로 **두 단**에 Part를 차례로 담고, 두 단의 줄 수가 가장 비슷해지는 Part 한 곳에서만 단을 나눕니다. 줄 간격도 조금 좁힙니다(2026-11-14). 예: Part 8개 × 장 2개(목차 32줄)까지 첫 쪽에 들어갑니다.
  - 그래도 목차가 한 쪽에 다 들어가지 않으면(목차 줄이 쪽 밖으로 밀리거나, 목차에 밀려 위 책 제목이 가려짐. 제목 그림 띠가 조금 낮아지는 것은 괜찮음) `toc-overflow` 경고가 납니다. `print.tocDepth`를 1로 줄이면 대개 해결됩니다.
- 어느 `part.json`에도 `print.cover`가 없으면 예전 구성(부마다 색 표지 `01` + 부 제목, 다음 쪽에 부 목차)입니다.

## 2. 장 원고 (`.md`)

### 2-1. 머리 부분

```markdown
---
title: 속도와 가속도
summary: 한 줄 요약
week: 1
---
```

- `title`(필수): 장 제목. 장 머리 띠와 오른쪽 쪽 머리말에 나옵니다.
- `summary`, `week` 등 다른 칸은 Physiklar용이며 인쇄에서는 쓰지 않습니다.
- 장 번호는 **책 전체에서 이어서** 자동으로 정합니다(부가 바뀌어도 1로 돌아가지 않음, 2026-11-07 사용자 결정). 식·그림 번호의 앞자리도 이 장 번호입니다.

### 2-2. 본문 구성

장 하나는 **개념(THEORY) 구간**과 **문제(PROBLEMS) 구간**으로 이루어집니다.

```markdown
(개념 구간: 머리 부분 바로 뒤부터)

::problems

(문제 구간: 여기부터 장 끝까지)
```

- `::problems` 한 줄이 문제 구간의 시작입니다. 없으면 장 전체가 개념 구간입니다.
- 두 구간은 각각 새 쪽에서 장 머리 띠로 시작합니다. 탭은 구간에 맞게 THEORY 또는 PROBLEMS가 켜집니다.
- 개념 구간은 **비대칭 2단**(좁은 단 + 넓은 본문), 문제 구간은 **대칭 2단**입니다. 좁은 단은 기본으로 펼친 책의 바깥쪽에 놓입니다(`sideColumn`). 개념 구간을 대칭 2단으로 나누지 않습니다.

## 3. 문법

표의 "출처"가 Physiklar인 것은 Physiklar에서 그대로 쓰는 문법이고, "편집기"인 것은 인쇄용으로 새로 더한 문법입니다.

### 3-1. 글자와 제목

| 문법 | 출처 | 인쇄 결과 |
|---|---|---|
| `## 제목` | 공통 | 절 제목 `1. 제목` (번호 자동) |
| `### 제목` | 공통 | 소제목 `(1) 제목` (번호 자동, `##`마다 다시 1부터) |
| `#### 제목` | 공통 | 번호 없는 작은 제목 |
| `**굵게**`, `*기울임*` | 공통 | 그대로 |
| `:hl[형광펜]` | Physiklar | 형광 강조 |
| `:red[…]` `:blue[…]` `:green[…]` | Physiklar | 색 글자(색 묶음의 인쇄 색으로) |
| `:::center` / `:::right` | Physiklar | 가운데·오른쪽 정렬(문제 안에서도). 편집기는 `:::left`도(가운데 상자 안 한 부분만 왼쪽). 도구 막대 "정렬 ▾" |
| 표(GFM) | 공통 | 테두리 있는 표(문제 안에서는 책 색 선·흰 바탕). 첫 줄과 둘째 줄(`|---|`)의 칸 수가 다르면 가장 많은 칸 수로 맞춰 그리고 `table-fixed` 경고. 둘째 줄의 `:--`(왼쪽) `:-:`(가운데) `--:`(오른쪽)로 칸 정렬(편집기 2026-11-12부터 인쇄에 반영). 문제 안의 표는 문제 글자 크기를 따라감 |
| `:::tab` … `:::` | 편집기 | **탭 맞춤**(테두리 없음). 줄마다 `\|` 자리를 세로로 맞춥니다. 앞 칸은 가장 긴 글 폭, 마지막 칸은 남는 폭 전부라 긴 글이 다음 줄로 넘어가도 그 칸의 시작에 맞춰집니다. `\|`가 없는 줄은 줄 전체 한 칸. `:::tab{center}`는 표를 가운데에 두고 칸도 가운데(테두리 없는 작은 표). 도구 막대 "탭 맞춤" |
| 목록 `-`, `1.` | 공통 | 목록 |

- `#` 한 개짜리 제목은 쓰지 않습니다(장 제목은 머리 부분의 `title`).
- 모르는 글자 디렉티브(`:abc`)는 원래 글자 그대로 둡니다. 예: "비율 1:abc" → 그대로.

### 3-2. 수식

| 문법 | 인쇄 결과 |
|---|---|
| `$F = ma$` | 본문 속 수식 |
| `$$ … $$` | 가운데 놓인 수식, 번호 없음 |
| `$$ … \label{coulomb} $$` | 번호가 붙는 수식 `(1.3)`. `\label{}`은 지워지고 번호로 바뀜 |
| `:ref[coulomb]` | 본문에서 그 수식 번호 `(1.3)` |

- 수식 번호는 `(장 번호.순서)`입니다.
- KaTeX가 지원하는 LaTeX만 씁니다. 수식 안 한글은 `\text{변위}`.

### 3-3. 인쇄에서 빼는 것

| 대상 | 출처 | 처리 |
|---|---|---|
| `:::quiz{answer=…}` … `:::` | Physiklar | 인쇄하지 않음. 원고에는 남김 |
| `::exp{id=…}`, `::anim{id=…}` | Physiklar | 인쇄하지 않음. 원고에는 남김 |
| `+++` (한 줄) | Physiklar | 화면 쪽 나눔. 인쇄에서는 무시 |
| `book.json`의 `omitSections`에 있는 제목의 절 | 편집기 | 그 제목부터 같은 단계 이상의 다음 제목 직전까지 통째로 뺌 |
| 위 처리로 내용이 비게 된 제목 | — | 제목도 뺌(예: 퀴즈만 있던 "도전 문제") |

- 기본으로 빼는 제목: `실험으로 확인하기`, `직접 해 보기`(브릿지 교재 기준).
- 원고에서 지우지 않는 이유: Physiklar로 되돌릴 때 잃지 않기 위해서입니다.

### 3-4. 상자

```markdown
:::note[제목]
내용
:::
```

| 이름 | 출처 | 제목이 없을 때 기본 제목 |
|---|---|---|
| `note` | Physiklar | 참고 |
| `tip` | Physiklar | 팁 |
| `warn` | Physiklar | 주의 |
| `think` | Physiklar | 더 생각해 보기 |

- `note`와 `think` 상자의 제목 앞에는 §(Section sign)가 붙습니다(예: "§ 더 생각해 보기"). 2026-11-07 사용자 요청.

### 3-4-0. 예제 (편집기)

```markdown
:::example[기울어진 렌치]
문제 상황 …

**풀이** 풀이 …
:::
```

- 제목 앞에 장마다 "예제 1", "예제 2", … 번호가 자동으로 붙습니다. 풀이까지 본문에 보이는 계산 예이므로 교사용·학생용 모두 보입니다(학생이 풀 문제는 `::::problem`).
- Physiklar로 내보낼 때는 `:::note[예제 · 제목]`으로 바뀝니다. 2026-11-09 사용자 요청.

### 3-4-1. 한 문장 정의 (편집기)

```markdown
:::def
**변위**란 처음 위치에서 나중 위치까지의 **위치 변화**이다.
:::
```

- 굵은 글씨·가운데 정렬로, 앞뒤에 독일식 따옴표 „ “(여는 따옴표는 아래쪽)가 붙습니다. 장마다 핵심 정의 몇 개에만 씁니다.
- Physiklar로 내보낼 때는 울타리 줄만 지웁니다.

### 3-5. 옆 단 (개념 구간 전용)

```markdown
:::side[대전과 대전체]
전기적 현상을 띠게 하는 것을 대전이라고 한다.
:::
```

- 개념 구간의 **좁은 단**(기본: 펼친 책의 바깥쪽)에, 원고에서 쓴 자리와 같은 높이에 놓입니다.
- 짧은 용어 풀이와 작은 그림용입니다. 안에 `::fig`를 넣을 수 있습니다.
- 출처: 편집기. Physiklar로 내보낼 때는 `:::note[제목]` 상자로 바뀝니다.
- 문제 구간에서 쓰면 경고하고 보통 상자로 처리합니다.

### 3-6. 그림

| 문법 | 출처 | 인쇄 결과 |
|---|---|---|
| `::fig[설명]{src=images/a.svg w=80}` | Physiklar | 그림 + 설명. `w`는 단 너비에 대한 % (기본 100) |
| `::fig[설명]{src=… w=80 #wave}` | 편집기 | 위와 같고, `:ref[wave]`로 그림 번호를 부를 수 있음 |
| `:::figs` 안에 `::fig` 여러 개 | 편집기 | 그림을 가로로 나란히(각각 설명 띠) |
| ` ```plot ` 블록 | 편집기 | 함수 그래프(3-9절) |

- 그림 번호는 `그림 (장 번호).(순서)`입니다. 옆 단(`:::side`) 안의 그림과 **문제 구간(`::problems` 아래, 연습문제 장 포함)의 그림**은 `#이름`이 있을 때만 번호를 붙입니다(2026-11-10).
- SVG 그림은 본문에 직접 넣습니다(그림 속 글자가 본문 글꼴을 쓰도록). PNG·JPG는 그대로 넣고, 인쇄 크기에서 300dpi보다 낮으면 경고합니다.
- 설명 띠의 모양(색 띠 위 글씨)은 테마가 정합니다.

### 3-7. 교사용·학생용

PDF를 뽑을 때 **판(edition)** 을 고릅니다: `teacher`(교사용) 또는 `student`(학생용). 원고는 하나입니다.

| 문법 | 교사용 | 학생용 |
|---|---|---|
| `:blank[알짜힘]` | 알짜힘 (강조색 + 밑줄) | 글자 수만큼 밑줄 칸 `_ _ _` |
| `:blank[$F=ma$]` | 수식 그대로 (강조색 + 밑줄) | 수식이 차지하던 폭만큼 밑줄 한 칸 |
| `:::teacher` … `:::` | 보임 | 같은 자리를 비워 둠(두 판의 쪽 위치를 맞추려고) |
| `:::source` … `:::` (문항 안) | 문항 번호와 같은 줄 오른쪽에 정답(강조 색 글씨, 표시 글자 없음) | 빠짐 |
| `:::solution` … `:::` (문항 안) | 문제 쪽에는 없음. 책 맨 뒤 "A 정답과 해설" 장에 | 교사용과 같음(맨 뒤 장에) |

- 밑줄 칸 하나의 폭 = 본문 한글 한 글자 폭. 띄어쓰기는 칸 사이 간격으로 남깁니다(`:blank[등가속도 운동]` → `_ _ _ _   _ _`).
- 두 판의 **줄바꿈과 쪽 번호가 같아야** 합니다. 이를 위해 빈칸은 교사용과 학생용에서 같은 폭을 차지합니다.
- Physiklar로 내보낼 때 `:blank[알짜힘]`은 "알짜힘", `:::teacher`·`:::source`·`:::solution`은 지웁니다.

### 3-8. 문제

```markdown
::problems

::::problem
그림과 같이 … 구하시오.

(1) A와 B의 전하량 크기를 비교하시오.

::space{h=30}

(2) A, B, C의 전하 종류를 각각 구하시오.

:::source
(1) A > B (2) A: (+), B: (−), C: (+)
:::

:::solution
(1) … (2) …
:::
::::
```

- `::::problem`(콜론 4개) 안에 `:::source`·`:::solution`(콜론 3개)을 넣습니다. 콜론 개수는 외울 필요가 없게 편집기의 "문제 추가" 버튼이 틀을 넣습니다.
- **정답과 해설을 나눠 씁니다**(2026-11-13 사용자 결정).
  - `:::source`: 교사가 한눈에 보고 바로 풀 수 있게 **간단한 정답과 풀이 정보**만. **교사용에서만** 문항 번호와 같은 줄 오른쪽에 보입니다(강조 색 글씨, "정답" 같은 표시 글자 없음, 한 쪽 2·4·6문항 모두, 2026-11-13 사용자 결정). 길면 그 줄이 늘어나 문제 글을 아래로 밉니다. 학생용에서는 빠집니다. 편집기 "정답(정)" 단추.
  - `:::solution`: 해설. 문항 아래 원고에 쓰지만 **문제 쪽에는 찍히지 않고**, 책 맨 뒤 **"A 정답과 해설"** 장에 모입니다. 이 장은 **교사용·학생용 모두**에 들어가 두 판의 쪽 번호가 같습니다. 편집기 "해설(해)" 단추.
  - **A부 정답과 해설**: 마지막 부 다음 자리에 번호를 세지 않는 부 "A"로 들어갑니다(2026-11-13). 다른 부처럼 부 쪽이 있고(큰 표지 구성은 흰 바탕 부 쪽 "정답과 해설", 기본 구성은 색 표지 "A 정답과 해설"), 이어지는 해설 쪽의 장 머리 띠 번호 자리도 `A`, 책 첫 쪽 목차 맨 끝에 `A 정답과 해설`. 2단, 작은 글씨(문제 글자 크기 × 8.4/9.6, 기본 7pt). **부 순서대로**, 부가 바뀔 때마다 작은 부 제목("1부 운동과 힘"), 문항마다 `001 해설 글`. 해설 상자·"해설" 표시는 없고, 해설 글은 원고 그대로 옮깁니다(정답 표기가 필요하면 해설 글 첫머리에 "정답 ④"처럼 씀). 해설이 없는 문항은 번호도 빠집니다. 해설이 하나도 없는 책에는 이 장이 없습니다.
  - 편집기 미리보기: "이 장"으로 볼 때는 그 장의 해설이 장 뒤에 붙고(A부 쪽 없이), 미리보기 범위 "A부 정답과 해설"을 고르거나 **장 목록 맨 끝의 "A. 정답과 해설"** 을 고르면(2026-11-13) 책 전체 해설을 모은 A부만 봅니다(편집 칸은 직전 장 그대로, 다른 장을 고르면 "이 장" 미리보기로 돌아감). 해설 줄에 커서를 두면 미리보기가 그 해설 자리로 갑니다. PDF는 늘 책 전체(맨 뒤 A부).
  - `:::solution`을 문항 밖에 쓰면 빼고 경고(`solution-outside-problem`)합니다.
- 문항 번호는 **책 전체로 이어서** 자동으로 붙습니다(2026-11-12 사용자 결정). 책의 첫 문항이 `001`이고, 1부 연습문제가 028번에서 끝나면 다음 문항은 `029`입니다. 책이 바뀌면 다시 `001`부터. 장마다 `001`부터 매기려면 `book.json`의 `print.problemNumbering: "chapter"`. 모양은 `problemNumber`.
- **문항마다 새 단에서 시작합니다.** 대칭 2단이므로 한 쪽에 두 문항입니다.
- **소문항이 많은 문항을 한 쪽에 하나**(한 쪽 2문항일 때, 2026-11-13): 문항 안 소문항 사이에 `::columnbreak`를 두면 그 뒤가 오른쪽 단으로 넘어갑니다(예: 왼쪽 단에 문제와 (1), 오른쪽 단에 (2)(3)). 다음 문항은 다음 쪽 왼쪽 단에서 시작합니다. 이 문항이 왼쪽 단에서 시작하도록 앞의 한 단 문항 수를 짝수로 맞춥니다. 일부러 나눈 단은 정답 넘침(`source-overflow`)으로 세지 않습니다.
- **쪽마다 문항 수를 다르게** 할 수 있습니다(2026-11-08): `::problems{first=4 per=6}` 는 첫 쪽(장 머리 띠가 있는 쪽)만 4문항, 다음 쪽부터 6문항. 문항 사이에 `::page{per=6}` 를 쓰면 거기서 새 쪽을 시작하고 그 뒤로 6문항씩(긴 문제는 `::page{per=4}`).
- 한 쪽에 **4문항·6문항**도 됩니다(2026-11-08). 장마다 `::problems{per=4}` 또는 `::problems{per=6}`, 책 전체는 `book.json`의 `print.problemsPerPage`(2·4·6, 기본 2). 한 단을 2칸(칸 높이 109 mm)·3칸(70 mm)으로 나누고 칸 사이에 점선을 긋습니다. 칸 높이가 고정이라 학생용 풀이 공간이 같고, 문항이 칸을 넘치면 `problem-overflow` 경고가 납니다. 교사용에서 정답(`:::source`)이 칸을 넘치면 다음 칸에 겹쳐 찍힙니다. 쪽 번호를 학생용과 같게 지키려는 것이며 저자가 허용했습니다(2026-11-13). 이때는 `source-spill` 알림만 납니다.
- **연습문제 장(Q 장)**(2026-11-10): 머리 부분(`---`) 뒤 첫 줄부터 `::problems`로 시작하는 장(그 앞에 빈 줄·HTML 주석만 있음)은 문제만 있는 장으로 봅니다. 장 번호를 쓰지 않아 뒤 장 번호가 밀리지 않고, 번호 자리(장 머리 띠·머리말·부 쪽 목차·책 목차·편집기 장 목록)에 `Q`를 씁니다. 빈 개념 쪽을 만들지 않고 바로 문제 쪽(짝수 쪽)으로 시작합니다. 제목은 `title`로 정합니다(예: `title: 1부 연습문제` → "Q. 1부 연습문제"). 부마다 마지막 장으로 두는 것을 생각한 것입니다. 편집기 ＋ 단추의 "연습문제 장"이 이 틀을 만듭니다.
- **5지선다** `:::choices` … `:::`(2026-11-10): 한 줄에 선지 하나씩 쓰면 ①②③④⑤가 차례로 붙습니다(빈 줄은 무시). 한 줄에 몇 개 놓을지는 가장 긴 선지의 글 폭으로 정합니다: 모두 짧으면 한 줄에 다섯(시험지처럼 사이를 고르게), 아니면 3개·2개·1개씩. 직접 정하려면 `:::choices{cols=2}`. 도구 막대 "선지(①)" 단추가 틀을 넣습니다.
- **짝짓기 선지**(2026-11-11): `:::choices` 안의 줄에 `|`가 있으면 테두리 없는 표가 됩니다. 첫 줄은 머리(`| (가) | (나)`), 다음 줄부터 왼쪽에 ①②③④⑤가 세로로 붙습니다. 줄 앞뒤의 `|`는 있어도 없어도 되고, 수식(`$|v|$`) 안의 `|`는 칸을 나누지 않습니다. 도구 막대 "선지 ▾ → 짝짓기 선지"가 틀을 넣습니다.

```markdown
:::choices
| (가) | (나)
속력 | 가속도
속력 | 운동량
가속도 | 운동량
:::
```
- **<보기> 상자** `:::bogi` … `:::`: 한 줄에 하나씩 쓰면 `ㄱ.` `ㄴ.` `ㄷ.` …이 붙고, 테두리 위 가운데에 "<보기>"가 나옵니다. 제목을 바꾸려면 `:::bogi[조건]`. 도구 막대 "보기(ㄱ)" 단추.
- **<제시문> 상자** `:::jesi` … `:::`(2026-11-12): <보기>와 같은 테두리에 "<제시문>"이 나오고, 안은 번호·들여쓰기·내어쓰기 없는 보통 글입니다. 본문과 같이 빈 줄로 문단을 나누고(그냥 줄바꿈은 이어 씀), 수식·굵게·빈칸·그림도 쓸 수 있습니다. 제목을 바꾸려면 `:::jesi[자료]`. 도구 막대 "제시문(제)" 단추.

```markdown
::::problem
이에 대한 설명으로 옳은 것만을 <보기>에서 있는 대로 고른 것은?

:::bogi
A의 속력은 $2v$이다.
B에 작용하는 알짜힘은 0이다.
:::

:::choices
ㄱ
ㄴ
ㄱ, ㄴ
ㄴ, ㄷ
ㄱ, ㄴ, ㄷ
:::
::::
```
- `::space{h=30}`: 학생이 풀 공간을 30mm 띄웁니다(소문항 사이 등). 두 판 모두에서 같은 공간을 차지합니다.
- 교사용 정답(`:::source`)은 문항 번호 줄 오른쪽에 들어갑니다. 한두 줄을 넘기면 문제 글을 밀어 내립니다. **정답이 그 단을 넘치면 경고**(`source-overflow`)합니다. 넘치면 교사용의 쪽 번호가 학생용과 어긋나기 때문입니다. 정답은 짧게 쓰고, 긴 풀이는 `:::solution`(맨 뒤 정답과 해설)에 씁니다.
- Physiklar로 내보낼 때 문제 구간은 지웁니다(앞으로 Physiklar의 문제 기능이 생기면 다시 정함).

### 3-9. 함수 그래프

````markdown
```plot
x: -1 .. 4
y: -1 .. 9
f: y = 2x + 1            "y=2x+1"
g: y = x^2 / 2
fill: f, 0 .. 3
slope: f, 1 .. 2
point: (0, 1)            "y절편"
w: 70
```
````

| 줄 | 뜻 |
|---|---|
| `x: a .. b`, `y: a .. b` | 그리는 범위(필수) |
| `이름: y = 식` | 함수. 식은 `+ - * / ^`, 괄호, `sin cos tan sqrt exp ln abs`, `pi`, 곱셈 생략(`2x`) 허용. 뒤의 `"…"`는 그래프 옆 이름표 |
| `fill: 이름, a .. b` | 그 함수와 x축 사이를 x=a~b에서 칠함 |
| `fill: 이름1, 이름2, a .. b` | 두 함수 사이를 칠함 |
| `slope: 이름, a .. b` | x=a~b의 기울기 삼각형(Δx, Δy 이름표) |
| `point: (x, y) "이름"` | 점과 이름표 |
| `grid: on` \| `off` | 눈금선(기본 off) |
| `w: 70` | 단 너비에 대한 %(기본 70) |
| `xlabel: t`, `ylabel: v` | 축 이름(기본 `x`, `y`). `off`면 숨김 |
| `xstep: 1`, `ystep: 100` | 눈금 간격을 직접 정함(기본은 자동). 문제 그래프에서 읽어야 할 값이 눈금에 오게 할 때 |

- 식의 변수는 `x`가 기본입니다. 식에 `x`가 없고 다른 글자가 하나뿐이면 그 글자를 변수로 씁니다(`y = 2t + 2` → 가로축 이름도 `t`). 이름 없이 `y = 식`만 써도 됩니다.

- 문제 구간(문제 단 84.5 mm)의 그래프는 개념 본문(132 mm)보다 좁으므로 그림 좌표를 단 폭에 비례해 줄여, 눈금·이름표 글자가 종이에서 개념 구간과 같은 크기가 됩니다(2026-11-12). 가로축 이름이 길면("추의 무게(N)") 화살표 오른쪽 대신 축 끝 아래에 놓습니다. 단위는 `시간(\mathrm{s})`처럼 `\mathrm{}`으로 감싸야 바로 선 글씨가 됩니다.
- 결과는 SVG이며 인쇄 색 묶음을 씁니다. 이름표 글자는 본문 글꼴과 KaTeX를 씁니다.
- 편집기에서 그래프마다 SVG·PNG로 내려받을 수 있습니다.
- Physiklar로 내보낼 때는 SVG 파일로 바꾸고 `::fig`로 바꿉니다.

## 6. 경고 목록

변환·조판 중 아래 상황은 오류로 멈추지 않고 경고로 알립니다. 편집기는 경고를 원고 줄 번호와 함께 보여 줍니다.

| 코드 | 상황 |
|---|---|
| `unknown-directive` | 모르는 상자·블록 디렉티브 |
| `missing-image` | 그림 파일 없음 |
| `low-dpi` | 인쇄 크기에서 300dpi 미만 |
| `bad-math` | KaTeX가 해석하지 못한 수식 |
| `unknown-ref` | `:ref[x]`의 대상이 없음 |
| `duplicate-label` | 같은 `\label`·그림 이름이 두 번 |
| `side-outside-theory` | 문제 구간에서 `:::side` |
| `source-overflow` | 교사용 정답(`:::source`)이 단을 넘침 |
| `source-spill` | (한 쪽 4·6문항) 교사용 정답이 칸을 넘쳐 다음 칸에 겹침. 알림 |
| `solution-outside-problem` | `:::solution`이 문항 밖에 있음(인쇄에서 뺌) |
| `problem-overflow` | 한 쪽 4·6문항일 때 문항이 칸을 넘침 |
| `plot-error` | 그래프 식·범위 오류 |
| `page-multiple` | 전체 쪽수가 인쇄소 배수(기본 16)에 맞지 않음. 더 필요한 빈 쪽 수를 알림 |
| `toc-overflow` | 책 첫 쪽 목차가 한 쪽에 다 들어가지 않음(목차 줄이 쪽 밖, 또는 목차에 밀려 위 책 제목이 가려짐). `print.tocDepth`를 1로 |
